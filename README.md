# 뿌요 오버레이 (Android)

게임 화면을 캡처해 추천 훑기 경로를 화면 위에 그려 주는 앱.

## APK 만들기 (GitHub Actions)
1. GitHub 에서 새 저장소를 만들고 이 폴더 내용 전체를 push (main 브랜치).
2. 저장소의 Actions 탭 → "Build APK" 실행이 끝나면 Artifacts 의 `puyo-overlay-debug-apk` 다운로드.
3. 압축을 풀어 나온 `app-debug.apk` 를 폰에 설치 (출처를 알 수 없는 앱 허용).

## 사용
1. 앱 실행 → 갱신 방식(기본: 버튼) / 훑을 칸 수 / 덱 색 설정 → "오버레이 시작".
2. '다른 앱 위에 표시', 알림, 화면 캡처 권한을 허용.
3. 뿌요 퀘스트로 이동 → 화면 위 작은 막대의 [분석] 을 누르면 경로가 번호와 함께 표시됨.
   [다음안] 2·3위 전환, [수동/자동] 갱신 방식 전환, ⠿ 드래그로 이동, ✕ 종료.
